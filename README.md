# Zorentiva Technologies website

Responsive dark-themed company website with animated Z logo, technology strip, clickable service detail panels, interactive portfolio concept cards, portfolio filters, project concept detail dialogs, about/process sections, and EmailJS contact form.

## Run locally

1. Open this folder in Command Prompt / Terminal.
2. Run `python -m http.server 8000`.
3. Open `http://localhost:8000`.

## Contact form

The contact form uses EmailJS. The current service ID, template ID, and public key are configured in `script.js`. EmailJS public keys are intended for client-side use. Configure allowed origins/domain restrictions in the EmailJS dashboard before publishing to your production domain.

## Portfolio note

Portfolio tiles are illustrative concept previews, not claims of completed client work. Project details show possible features, tools, and roadmaps; the final stack and scope should be agreed with each client.


## Founder and team section
The About page now includes founder/team profile cards with illustrated portrait placeholders, plus an expanded “How we work” value section. Replace the placeholder names, bios, and illustrated portraits with the real founders’ names, bios, and photos before publishing. Do not present placeholder illustrations as real founder photos.


Founder profiles use the two original founder photos provided by the user. The photo files are copied byte-for-byte and are not retouched or altered.
